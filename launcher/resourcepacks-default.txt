# Every resource pack the pack ships, switched on for a player who has already
# played.
#
# The game reads its seed options (configureddefaults/options.txt) only when an
# instance has none, so without this list an existing player would receive these
# files and never see them selected. The launcher applies the list once per
# version of it - change a line and every instance gets it again - and after
# that the choice is the player's: a pack switched off stays off.
#
# Order is the game's own: a later line sits above an earlier one where two
# packs redraw the same thing, and the launcher gives the whole list this order
# in an instance that already has some of it. Gray's Mob Overhaul is last, and
# so on top, since it and Cute Mob Models both redraw the mobs. The five packs
# the pack shipped without ever switching on sit directly beneath it: none of
# them touches a mob, so the order above them is the one the pack has always
# had.
#
# "!" marks a pack built for an older game; it plays, but the game keeps such
# packs in a list of its own and would otherwise ask about them every launch.
